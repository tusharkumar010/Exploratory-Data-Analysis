📊 Real Estate & Music Data Analytics
(MagicBricks EDA + Spotify Data Analysis)

This repository contains two end-to-end data analytics projects focused on extracting insights from Real Estate (MagicBricks) and Music Streaming (Spotify) datasets using EDA, visualization, and machine learning techniques.

🚀 Projects Overview
🏠 1. MagicBricks Real Estate Analysis

An exploratory data analysis project on real estate listings to understand property pricing trends, location insights, and key influencing factors.

🎧 2. Spotify Data Analytics

A comprehensive analysis of Spotify data to uncover music trends, user preferences, and audio feature impact on song popularity.

📌 Objectives
MagicBricks
Analyze housing price distribution
Identify key factors affecting property prices
Compare locations and property types
Detect trends in real estate market

Spotify
Analyze audio features like danceability, energy, tempo
Understand factors influencing song popularity
Study trends across artists, genres, and years
Build predictive models for popularity
